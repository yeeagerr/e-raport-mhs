
# E-Report Student

E-Report Student is a web-based application designed to streamline and simplify the process of managing student academic reports. Built with a focus on usability and efficiency, this project allows teachers and administrators to create, update, and share student report cards with ease. With role-based access, intuitive UI, and secure data handling, E-Report Student is a practical tool for modern educational institutions.

## Lessons Learned

While building E-Report Student, I learned the importance of role-based access control, secure data handling, and designing a user-friendly interface for different types of users. I also improved my skills in managing form data, authentication, and integrating frontend with backend systems. The project challenged me to think about real-world usability, especially in an educational context.



## Features

🔐 Role-based access — Separate dashboards and permissions for Admin, Teacher, and Student

🖥️ Fullscreen mode — Clean, distraction-free workspace

📊 Student report management — Easily create, update, and share academic records

🔎 Search & filter — Quickly find students or reports with smart filters

🧾 Print-ready reports — Export or print student report cards with one click

🛠️ Secure authentication — Protected login system to ensure data privacy


## Installation

Clone github

```bash
  git clone https://github.com/yeeagerr/e-raport-mhs
```

Installation with laravel

```bash
cd e-raport-mhs
composer install 
composer key:generate
php artisan migrate 
```

Run with laravel

```bash
php artisan serve 
```
    
## Tech Stack

**Client:** TailwindCSS, Javascript

**Backend:** Laravel 10, Mysql
